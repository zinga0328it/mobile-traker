# Mobile Traker — laboratorio modulare

Repository condiviso per la ricerca e lo sviluppo **autorizzati** di un'applicazione modulare.

- Branch di coordinamento: `lia`
- Branch operativi: `agents/<host>/<ruolo>`
- Ogni contributo passa attraverso pull request e verifica prima di essere integrato.
- Il codice di produzione non va pubblicato su `main` prima dei controlli e dell'approvazione umana.

> **Sicurezza:** il repository è pubblico. Non caricare APK proprietari o sospetti, dati personali, registrazioni, credenziali, token, chiavi o output di analisi contenenti dati riservati. Le analisi di software di terzi devono essere autorizzate. Sono escluse funzionalità di sorveglianza occulta o raccolta di dati senza consenso.

La documentazione operativa è mantenuta nel ramo `lia`.
